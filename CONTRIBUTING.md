# Contributing

Thank you for taking an interest in the Trindle website. It really is appreciated.

The way this project is set up, the pages are written and kept in one place, so we cannot take code changes from outside. That has nothing to do with the quality of anyone's work. It works best when we hear what is wrong and fix it ourselves.

So the most useful thing you can send is a description:

- **Something wrong on a page?** Open an issue and tell us which page, what you did, what you expected, what happened, and which browser and device you used.
- **A mistake in the words?** Tell us what it says and what it should say.
- **Something you could not use?** A page that was hard to read, reach with a keyboard or use with a screen reader is exactly what we want to hear about.
- **A security problem?** Please do not use a public issue. Follow [SECURITY.md](SECURITY.md).

You are also free to fork the repository and make it your own. The licence is in [LICENSE](LICENSE).
