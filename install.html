Putting it on a computer

Write the image to a USB stick, start the computer from it, and try Trindle before you change anything on the disk. When you are ready, the Trindle Installer asks four things and does the rest.

Trindle is a whole operating system, and the image is the only way to install it. It cannot be added to a Debian you already have.

Try it from the stick for as long as you like, and think twice before making it the only system on a computer you depend on. Installing replaces everything on the disk you choose, or makes an existing partition smaller to make room beside it, and that cannot always be undone.

What you need

A computer64-bit Intel or AMD.
Disk spaceThe installer needs a disk of at least 20 GB. It has been tested on a 30 GB disk.
MemoryThe installer needs at least 1 GB of memory.
EncryptionThe installer can encrypt the disk only on a computer that starts with UEFI, not on one that starts the old BIOS way.
WindowsIf Windows was left hibernated or in fast start-up, the installer won't shrink it or write to it.
A USB stickA stick big enough for the image. Everything on it is replaced.
TimeAllow enough time so you aren't rushed. Don't start it just before you need the computer.

From the image to a running desktop

Five steps. Nothing on the computer changes until you press Install on the installer's Ready page, and then once more to confirm.

  1. Download the image.One .iso file, from the download page, which also shows its SHA-256 and signature.
  2. Write it to a USB stick.Use Impression, balenaEtcher or dd, described below. Everything already on the stick is replaced.
  3. Start the computer from the stick.Plug it in, switch on and hold the key for the boot menu. That is F12 on many computers, F9 on others, and Escape or F11 elsewhere. We haven't tried Trindle with Secure Boot on yet. If the computer won't start from the stick, turn Secure Boot off in the firmware settings.
  4. Try Trindle.It runs from the stick, with the ring, Apps and Settings all working. Nothing is written to the computer's own disk. Open the ring, look round, and decide.
  5. Press Install Trindle.It is the main button on the welcome window, and it is among the favourites in the ring too. This starts the Trindle Installer, which still changes nothing until you press Install on its Ready page.
Read this before you write a USB stick. Install it on a spare computer, or alongside a system you can still start, and back up anything on the disk that matters to you.

Impression

On Linux, the simplest of the three, from Flathub. Choose the .iso file, choose the USB stick, press Write and type your password when it asks.

balenaEtcher

Works on Windows, macOS or Linux. Choose Flash from file, select the target, then press Flash. It checks what it wrote afterwards, which is worth the extra minute.

dd

On Linux, if you would rather use the terminal. Run lsblk first, to be certain which device the stick is.

sudo dd if=IMAGE.iso of=/dev/sdX \
     bs=4M status=progress oflag=sync

/dev/sdX is the stick itself, not a partition on it. Getting this wrong wipes the wrong disk.

What the Trindle Installer asks

The installer asks four questions, then shows a summary in sentences. The mark rolls one stop along its line at each step, so you can always see where you are and how much is left. The Back button works until the install starts. Nothing is written until you press Install on the Ready page and then press it again to confirm.

Language

Choose it once and the keyboard and the time follow it. You can still change each one. There is a box to type in, so you can check the keyboard is really the one you meant before you rely on it for a password.

The disk

You can use the whole disk, which replaces everything on it. Or you can keep what is there, Windows or another Linux, and share the disk. A slider chooses how much room each side gets, and the installer says in plain words how much is left for what is there now and how much goes to Trindle.

Each disk is named by what is on it, so on a computer with two you pick the right one.

A swap file

The installer offers a swap file the size of the computer's memory. It is on to begin with, and the installer makes it only where the disk has plenty of room to spare. It gives the computer room to hibernate, which keeps everything open while the power is off, and somewhere to turn when memory runs short. It is kept out of the snapshots.

If Secure Boot is on, the installer says plainly that this computer can't hibernate, and that the swap file still helps when memory runs short.

Whether to encrypt the disk

You can choose a password that you type before anything else appears, or this computer's TPM chip. The chip unlocks the disk itself, so after the first start you type nothing at start-up. The first start still asks for the password once, while the chip learns the computer. The installer says which of the two this computer can do. Or you can leave the disk unencrypted. The installer asks for the password twice, and a button suggests a passphrase.

At each start you type the password on the keyboard you chose under Language. The box has an eye to show what you typed, and Tab does the same.

You

Enter your name, the name you sign in with, a name for the computer, and your password twice. Then a Ready page tells you the whole plan in sentences. Nothing has been changed yet.

Dual boot

If there is a Windows partition, or a Linux one of the ext2, ext3 or ext4 kind, with room in it, the installer offers to keep it and share the disk. It makes that partition smaller, leaving a margin of free space inside it, and puts Trindle in the space that opens up. It shares the boot partition that is already there. A disk with no boot partition to share can't take Trindle alongside what is on it, and the installer tells you so instead of guessing.

Afterwards both systems are in the boot menu, and the computer starts whichever you choose. If Trindle is on its own, the menu stays hidden because there is nothing to choose. Press Esc while the computer starts to see it.

Before you resize anything, back up the other system. Let Windows shut down properly instead of hibernating, or its partition can't be made smaller.

The first ten minutes afterwards

What to do once you are logged in and looking at the desktop.

Pick some apps

The Welcome offers common apps. Pick what you want and press Install the chosen apps. Almost nothing is installed to begin with, and that includes a web browser.

Join the Wi-Fi

Open the ring, click the Wi-Fi icon in the middle, switch Wi-Fi on, press Connect beside your network and, if it asks, type the password and press Join.

Set the screen size

Open Settings, Display, Size. If a change looks wrong, do nothing and it puts itself back after fifteen seconds.

Switch locking on

Open Settings, Power. Locking is off to begin with. Once it is on, your password unlocks the computer, or a four-digit PIN if you also choose one.

Help is built in. Settings has a Help page, and it works with the network off. Every page in Settings has a small i beside its name that explains the page.
