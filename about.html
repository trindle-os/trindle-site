Why this exists

Desktops have grown a bar at the top, a dock at the bottom, a tray in one corner and a search box that wants the keyboard. Trindle puts all of it in one circle that is not there until you ask for it.

It is in beta testing now. It is still new to other people’s computers, and it keeps changing.

One program, not a pile of them

The ring, Settings, Apps, Screenshot, Activity, Drives, the login screen, the lock screen and the Trindle Installer are all the same Rust binary. Nearly every trindle- command is a symbolic link to it, and the program picks its tool by the name it was started as. trindle --names lists them. The spots in the top corners that a finger taps to open the ring, and the box that asks for your password, go a step further and run inside the ring itself, rather than as two programs of their own, each with its own copy of the toolkit.

The compositor, which puts every window on the screen, is Trindle’s own too. It is called trindle-compose, it is written in Rust on Smithay, and it is kept as a program of its own, so the rest of Trindle never loads what drawing the screen directly needs. It runs the login screen as well as the desktop. For programs that ask the desktop to draw their title bar, it draws the title bar itself, with three buttons at the right: a line to put the window away, a square to fill the screen and a cross to close it.

That is not a clever trick for its own sake. It means one set of colours, one stylesheet, one place a bug gets fixed, and one thing to keep up to date. A new Settings page is one file in a folder plus one line in that folder's list.

Only trindle-admin runs as root, through pkexec. It checks every argument it is given and reads passwords from standard input only, so the rest of the desktop never needs to be trusted with them.

What it is built on

Debian stable underneath, with apt and Flatpak behaving exactly as they do anywhere else. The Debian underneath follows Debian stable’s own release programme. The Trindle desktop on top is a rolling release: new versions arrive as ordinary updates from Trindle’s own source, so you do not wait for a new version of the whole system to get a newer desktop. PipeWire for sound, NetworkManager, BlueZ, CUPS, snapper. Trindle’s own windows are drawn by the Trindle Toolkit, its own Rust drawing library, and its compositor is built on Smithay, the Rust toolkit for compositors.

What it deliberately is not

There is no X11 session and no GNOME session, and Trindle’s own windows use neither GTK nor Qt. Xwayland is installed for older programs written for X11, and Trindle’s compositor starts it with the desktop, never at the login screen. Nothing is installed with recommended extras, and every package is listed in the README.

Ordinary underneath

Underneath the desktop are standard parts. The snapshots are snapper’s, the sound is PipeWire, the apps come from Flathub as Flatpaks, as AppImages or from Debian, and your settings are plain files in your home folder.

It is new

Trindle is built on Debian stable, which is 13 at the time of writing, and has been tested on a small number of machines.

Things move between versions. There is no support desk: bugs and questions go to distro@trindle.org.

Free software, and meant to stay that way

Trindle is under the GNU General Public License, version 3 or later. You may use it, read it, change it and pass it on, and anything you pass on carries the same freedom with it.

The source repository is public at github.com/trindle-os (opens in a new tab), and holds this website and the script that builds the installation image. Bug reports are welcome, and so is someone telling us a screen is confusing, which is harder to find out than a crash. Trindle is built to one specification, so pull requests are not the usual way in: describe your fix or idea in a report instead. Forking it is welcome.

Questions people ask

What is Trindle?

A whole operating system built on Debian stable, with a desktop that lives in one ring and a Wayland compositor of its own. It installs only from its own image, and it is written in Rust with its own toolkit.

No. Trindle has no account and no telemetry. This site sets no cookies and counts no visitors.
