Why this exists

Desktops have grown a bar at the top, a dock at the bottom, a tray in one corner and a search box that wants the keyboard. Trindle puts all of it in one circle that is not there until you ask for it.

It is still new to other people's computers, and it keeps changing.

In short

WhatA whole operating system built on Debian stable, with a desktop that lives in one ring and a Wayland compositor of its own. It installs only from its own image
Written inRust, with its own toolkit
ShapeOne program, beside its own compositor and the disk-password screen. Every other trindle- command is a link to the same binary

One program, not a pile of them

The ring, Settings, Apps, Screenshot, Activity, Drives, the login screen, the lock screen and the Installer are all the same Rust binary.

One programNearly every trindle- command is a link to it, and it picks its tool by the name it was started as. trindle --names lists them.
Its own compositortrindle-compose, written in Rust on Smithay, puts every window on the screen and runs the login screen too. It is a program of its own, so nothing else loads what drawing the screen needs.
WhyOne set of colours, one stylesheet, one place a bug gets fixed. A new Settings page is one file and one line in a list.
Only one runs as roottrindle-admin, through pkexec. It checks every argument and reads passwords from standard input only.

What it is built on

Debian stableUnderneath, with apt and Flatpak behaving as they do anywhere else, and following Debian's own release programme.
A rolling desktopTrindle on top arrives as ordinary updates from Trindle's own source, so you do not wait for a new version of the whole system.
Parts usedPipeWire, NetworkManager, BlueZ, CUPS and snapper, with Trindle's own Rust toolkit for windows and Smithay for the compositor.

What it deliberately is not

There is no X11 session and no GNOME session, and Trindle's own windows use neither GTK nor Qt. Xwayland is installed for older programs written for X11, and Trindle's compositor starts it with the desktop, never at the login screen. Nothing is installed with recommended extras, and every package is listed in the README.

Ordinary underneath

Underneath the desktop are standard parts. The snapshots are snapper's, the sound is PipeWire, the apps come from Flathub as Flatpaks, as AppImages or from Debian, and your settings are plain files in your home folder.

It is new

Trindle is built on Debian stable, which is 13 at the time of writing, and has been tested on a small number of machines.

Things move between versions. There is no support desk: bugs and questions go to distro@trindle.org.

Questions people ask

What is Trindle?

A whole operating system built on Debian stable, with a desktop that lives in one ring and a Wayland compositor of its own. It installs only from its own image, and it is written in Rust with its own toolkit.

Is Trindle free software?

Yes. Trindle is under the GNU General Public License, version 3 or later. You may use it, read it, change it and pass it on, and anything you pass on carries the same freedom with it.

Does Trindle track me?

No. Trindle has no account and no telemetry. This site sets no cookies and counts no visitors.

Is it ready for everyday use?

It is new, it has been tested on a small number of machines, and it keeps changing. Back up everything that matters before you install it, because it changes how the computer starts, logs in and manages its disks.

What is it built on?

Debian stable underneath, with apt and Flatpak behaving as they do anywhere else. The desktop on top is a rolling release, so new versions arrive as ordinary updates without waiting for a new version of the whole system.

Where do I get help?

There is no support desk. Bugs and questions go to distro@trindle.org. Bug reports are welcome, and so is someone telling us a screen is confusing.

Can I send code?

Trindle is built to one specification, so pull requests are not the usual way in. Describe your fix or idea in a report instead. Forking it is welcome.
