What sets it apart

Each of these works today.

A clean screen

No bar, no panel and no clock on the desktop. The ring holds the time, sound, Wi-Fi, updates, your programs and your windows.

Draw before you keep

Press Print and the screen freezes. Mark it with arrows, boxes, blur or numbered spots, then copy, save or pin it.

A permission window like a phone’s

Every app lists what it wants in plain words, with a switch for each, all off until you choose.

You know when you are watched

A dot in the corner whenever an app uses the camera, the microphone or records the screen.

Apps cannot stop it starting

Only what the computer itself needs is installed system-wide. Apps may not add drivers or background services.

Its own compositor

The program that draws every window and takes every key is Trindle’s own, written in Rust. No plugin can reach into it.

Adverts and bad sites blocked

One switch blocks adverts, trackers and known bad sites for every browser and app, with private name lookups.

Coding agents in a box

Coding assistants can read logs and run commands, inside a fence that hides your personal files.

See the whole desktop

Kept apart, and in your hands

Programs live in boxes, an assistant works inside a fence, and every change can be undone.

Programs live in boxes

Every .deb, Flatpak, AppImage and plugin runs in a box that starts with no network, no microphone and none of your files. An app gets only what you allow.

How the boxes work

An assistant, inside a fence

A built-in MCP server lets an assistant such as Claude see how the computer is doing, once you point it there. It asks on screen before any change, takes a snapshot first, and can undo.

About the assistant

A way back, and a locked disk

A snapshot is taken around every change, and your home folder is copied each day. At install you can encrypt the disk with a password or the computer’s TPM chip, or leave it open.
